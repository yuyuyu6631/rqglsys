# 燃气管理系统前端修复手册

## 概述

本手册记录了前端代码中的已知问题及修复方案，供开发团队参考执行。

## 一、TypeScript 类型问题

### 1.1 `any` 类型滥用（高优先级）

**问题描述**：多个文件使用了 `any` 类型，降低了类型安全性。

**涉及文件及位置**：

| 文件 | 行号 | 代码 |
|------|------|------|
| `Layout.tsx` | 32 | `icon: any` |
| `OrderManage.tsx` | 78 | `icon: any` |
| `AnnouncementManage.tsx` | 77, 89 | `err: any` |
| `CylinderManage.tsx` | 85, 97 | `err: any` |
| `DeliveryOrders.tsx` | 32 | `err: any` |
| `Login.tsx` | 37 | `err: any` |
| `SafetyCheck.tsx` | 61 | `err: any` |
| `UserManage.tsx` | 94, 106 | `err: any` |
| `UserOrder.tsx` | 38 | `err: any` |
| `UserOrders.tsx` | 42, 63 | `err: any` |
| `api.ts` | 多个位置 | 多处 `any` |

**修复方案**：

1. **图标类型修复**（Layout.tsx, OrderManage.tsx）：
```typescript
import type { LucideIcon } from 'lucide-react';

// 修改类型定义
const menuConfig: Record<string, { icon: LucideIcon; label: string; path: string }[]> = {
  // ...
}
```

2. **错误类型修复**：
```typescript
// 定义 API 错误类型
interface ApiError {
  response?: {
    data?: {
      error?: string;
    };
  };
  message?: string;
}

// 使用类型断言
try {
  // ...
} catch (err: unknown) {
  const error = err as ApiError;
  alert(error.response?.data?.error || '操作失败');
}
```

## 四、API 层类型定义

### 4.1 api.ts 中的 any 类型

**修复方案**：

在 `types/index.ts` 中添加请求/响应类型：

```typescript
// 通用 API 响应类型
export interface ApiResponse<T> {
    data: T;
    message?: string;
    code: number;
}

// API 错误类型
export interface ApiError {
    response?: {
        data?: {
            error?: string;
            message?: string;
        };
        status?: number;
    };
    message?: string;
}

// 请求参数类型
export interface CylinderParams {
    status?: string;
    specs?: string;
    keyword?: string;
}

export interface OrderParams {
    status?: string;
    startDate?: string;
    endDate?: string;
}
```

然后修改 `api.ts`：

```typescript
import type { ApiResponse, ApiError, CylinderParams, OrderParams } from '../types';

// 修改 api 实例
const api = axios.create({
    baseURL: '/api',
    withCredentials: true,
    headers: {
        'Content-Type': 'application/json',
    },
});

// 带类型的 API 方法
export const cylinderApi = {
    getCylinders: (params?: CylinderParams) =>
        api.get<ApiResponse<Cylinder[]>>('/cylinders', { params }),
    // ... 其他方法
};
```
