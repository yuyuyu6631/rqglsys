# 燃气钢瓶管理系统后端接口文档

更新时间：2026-03-20  
默认开发地址：`http://127.0.0.1:5010`

## 1. 说明

- 接口前缀：`/api`
- 认证方式：Session Cookie
- 内容类型：`application/json`
- 文件上传：`multipart/form-data`
- 统一错误格式：

```json
{
  "error": "错误说明"
}
```

## 2. 认证接口

### 2.1 登录

- 方法：`POST`
- 路径：`/api/auth/login`

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

响应：

```json
{
  "message": "登录成功",
  "user": {
    "id": 1,
    "username": "admin",
    "role": "admin"
  }
}
```

### 2.2 当前登录用户

- 方法：`GET`
- 路径：`/api/auth/me`

### 2.3 退出登录

- 方法：`POST`
- 路径：`/api/auth/logout`

## 3. 用户管理

### 3.1 用户列表

- `GET /api/users`
- 权限：`admin`、`station`
- 查询参数：`role`

### 3.2 用户详情

- `GET /api/users/{id}`
- 权限：`admin`、`station`

### 3.3 创建用户

- `POST /api/users`
- 权限：`admin`

请求体示例：

```json
{
  "username": "delivery02",
  "password": "123456",
  "role": "delivery",
  "real_name": "李配送",
  "phone": "13800138000",
  "station_id": 1
}
```

### 3.4 更新用户

- `PUT /api/users/{id}`
- 权限：`admin`

### 3.5 删除用户

- `DELETE /api/users/{id}`
- 权限：`admin`
- 限制：当前登录用户、有关联订单/安检/公告/评价的用户不可删除

## 4. 钢瓶管理

### 4.1 钢瓶列表

- `GET /api/cylinders`
- 查询参数：`status`、`specs`

### 4.2 钢瓶详情

- `GET /api/cylinders/{id}`

### 4.3 创建钢瓶

- `POST /api/cylinders`
- 权限：`admin`、`station`

请求体示例：

```json
{
  "serial_code": "CYL20260320001",
  "specs": "15kg",
  "status": "in_stock",
  "manufacturer": "中燃集团",
  "manufacture_date": "2025-01-01",
  "expiry_date": "2028-01-01",
  "station_id": 1
}
```

### 4.4 更新钢瓶

- `PUT /api/cylinders/{id}`
- 权限：`admin`、`station`

### 4.5 更新钢瓶状态

- `PUT /api/cylinders/{id}/status`
- 权限：`admin`、`station`、`delivery`

请求体：

```json
{
  "status": "delivering"
}
```

状态流转：

- `in_stock -> delivering`
- `delivering -> in_use / in_stock`
- `in_use -> empty`
- `empty -> in_stock`

### 4.6 删除钢瓶

- `DELETE /api/cylinders/{id}`
- 权限：`admin`、`station`
- 限制：`delivering`、`in_use` 状态不可删除

### 4.7 钢瓶总览统计

- `GET /api/cylinders/stats`

返回字段：

- `in_stock`
- `delivering`
- `in_use`
- `empty`
- `expiring_soon`
- `total`

## 5. 订单管理

### 5.1 订单列表

- `GET /api/orders`
- 查询参数：`status`
- 权限过滤：
- 普通用户只能看到自己的订单
- 配送员只能看到分配给自己的订单
- 管理员和站点人员可查看全部

### 5.2 订单详情

- `GET /api/orders/{id}`

### 5.3 创建订单

- `POST /api/orders`

请求体示例：

```json
{
  "specs": "15kg",
  "quantity": 2,
  "address": "上海市浦东新区测试路 88 号",
  "contact_name": "张三",
  "contact_phone": "13900139000",
  "remark": "下午送达"
}
```

### 5.4 分配订单

- `PUT /api/orders/{id}/assign`
- 权限：`admin`、`station`

请求体：

```json
{
  "delivery_id": 5
}
```

说明：

- 只能分配 `pending` 订单
- 分配时会自动锁定对应数量的在库钢瓶
- 返回结果中新增：
- `allocated_cylinder_ids`
- `allocated_cylinders`

### 5.5 更新订单状态

- `PUT /api/orders/{id}/status`

请求体：

```json
{
  "status": "completed"
}
```

状态流转：

- `pending -> assigned / cancelled`
- `assigned -> delivering / cancelled`
- `delivering -> completed`

业务规则：

- 用户只能取消自己的 `pending` 订单
- 配送员只能处理分配给自己的订单，并且只能改成 `delivering` 或 `completed`
- 订单取消时会释放已锁定钢瓶回到 `in_stock`
- 订单完成时已分配钢瓶会自动改为 `in_use`

## 6. 安检管理

### 6.1 安检记录列表

- `GET /api/safety/records`
- 查询参数：`hazard_level`

### 6.2 安检记录详情

- `GET /api/safety/records/{id}`

### 6.3 创建安检记录

- `POST /api/safety/records`

请求体示例：

```json
{
  "order_id": 1001,
  "check_items": "阀门正常，软管正常",
  "hazard_level": "low",
  "hazard_description": "软管略老化",
  "photos": [
    "photo1.jpg",
    "photo2.jpg"
  ]
}
```

### 6.4 更新安检记录

- `PUT /api/safety/records/{id}`

### 6.5 删除安检记录

- `DELETE /api/safety/records/{id}`

### 6.6 上传安检照片

- `POST /api/safety/upload`
- 表单字段：`file`
- 支持扩展名：`jpg`、`jpeg`、`png`、`gif`、`webp`

响应示例：

```json
{
  "filename": "20260320153000_ab12cd34.jpg",
  "url": "/uploads/20260320153000_ab12cd34.jpg"
}
```

### 6.7 访问上传文件

- `GET /uploads/{filename}`

## 8. 评价管理

### 8.1 创建评价

- `POST /api/ratings`

请求体：

```json
{
  "order_id": 1001,
  "score": 5,
  "comment": "配送及时，服务很好"
}
```

限制：

- 只能评价自己的订单
- 只能评价已完成订单
- 一个订单只能评价一次

### 8.2 评价列表

- `GET /api/ratings`
- 查询参数：`order_id`

### 8.3 评价详情

- `GET /api/ratings/{id}`

### 8.4 获取订单评价

- `GET /api/orders/{id}/rating`

- `GET /api/stats/delivery/ranking`
